# TNT 1.2.2 modelling record

1. Open TNT 1.2.2.
2. Create a new two-conductor transmission-line model.
3. Select the dielectric layer and specify its material and dimensions.
4. Select the ground plane and specify its dimensions.
5. Place the dielectric layer on the ground plane.
6. Place two rectangular conductors with the dimensions specified in the test case.
7. Vary only the parameter requested in the test case; keep other dimensions fixed.
8. Run the model and record characteristic impedance and propagation velocity.
9. Save the model and capture the actual output/results window.

The master record does not provide a SCILAB program for this experiment. Do not substitute a made-up SCILAB result for the TNT simulation.
