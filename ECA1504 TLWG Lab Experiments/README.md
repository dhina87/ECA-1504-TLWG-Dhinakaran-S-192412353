# ECA15 – Transmission Lines & Waveguides Laboratory

## Software / tools
- SCILAB 6.1.1: Experiments 1–13 
- TNT 1.2.2: Experiments 14–16 

## Repository layout
Each experiment has its own folder. SCILAB experiments contain `.sce` source files and an output note. TNT experiments contain the setup procedure and the output values transcribed from the master record.

## Running a SCILAB program
1. Open SCILAB 6.1.1.
2. Open the required `program.sce`.
3. Run the file.
4. Compare the console output with the experiment's `output-notes.txt`.
5. Save your own execution output or screenshots in that experiment folder.

## Important
- This repository is a study/work scaffold based on the ECA15 Subject curriculum 
- Check parameter units and test-case values against your lab faculty's instructions before submission.
- `output-notes.txt` files are guidance, not claims that the program was executed on your computer. Run each program and retain your actual output.
- Experiments 14–16 in the master record use TNT 1.2.2 graphical modelling; no SCILAB program is specified for those experiments.
